# AI-Powered Real-Time Voice Translation

## Project Overview

LinguaCall-AI is a browser-based, AI-mediated voice communication system that enables two callers speaking different languages to communicate through speech recognition, translation, transliteration, and text-to-speech.

The project is developed as a Software Engineering mini-project by Team TECHPOOL.

## Objectives

- Capture speech through the browser microphone.
- Convert speech into text using Speech-to-Text (STT).
- Translate recognized text into the receiving caller's language.
- Provide optional transliteration for supported languages.
- Generate translated speech using Text-to-Speech (TTS).
- Support bidirectional communication between two callers.
- Display live conversation transcripts with speaker labels and timestamps.

## Supported Languages

- English
- Hindi
- Kannada

## Technology Stack

- Frontend: React and Vite
- Backend: Node.js and Express
- Real-time communication: Socket.IO
- Database: PostgreSQL or another agreed relational database
- AI services: Speech-to-Text, translation, transliteration, and Text-to-Speech APIs

*The final technologies and service providers will be confirmed based on the implemented system.*

## Project Scope

This project focuses on a browser-based, two-party voice communication prototype. Direct PSTN/mobile carrier integration and training AI models from scratch are outside the current scope.
